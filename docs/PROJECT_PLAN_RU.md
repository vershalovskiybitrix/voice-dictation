# План VoiceService

## Сделано

- PTT по правому Ctrl.
- Toggle-диктовка по Scroll Lock.
- Нарезка длинной Scroll Lock-диктовки по паузе.
- Пробел между частичными chunk-результатами.
- Окно настроек из трея и double-click по иконке.
- История последних текстов текущего запуска.
- Кэш последних аудиозаписей.
- Чтение буфера и выделенного текста.
- Двойной короткий правый Ctrl для чтения выделенного текста.
- TTS-провайдеры: Piper, Silero, Yandex, текущий Google Translate.

## В работе / нужно довести

- Windows SAPI удалён из проекта: качество непригодное, в нормальном сценарии не нужен.
- Проверить Silero из окна приложения: CLI smoke-test работает, но в UI нужен явный статус запуска/ошибки, чтобы не выглядело как отсутствие реакции.
- Silero `v5_ru` не многоязычный: английский текст надо маршрутизировать в другой TTS или подключать отдельную EN-модель.
- Yandex: в текущем адаптере используется SpeechKit API v1, поэтому в списках должны быть только v1-совместимые русские голоса и роли.
- Сохранять последние результаты распознавания на диск, чтобы можно было диагностировать потери текста после перезапуска.
- Проверить, почему отдельные chunk-распознавания иногда стартуют с заглавных букв или теряют первый сегмент.
- После завершения работ удалить `VOICE_SERVICE_TZ.md`, потому что там были секреты и мусор кодировки.

## Текущие приоритеты

1. Стабильная диктовка: PTT и Scroll Lock не ломать.
2. Чистые chunk-стыки: пробел есть, случайное троеточие на паузе убирается.
3. Читалка: Yandex как рабочий эталон, Silero/Piper как локальные кандидаты. Текущий Google Translate оставить как рабочий веб-провайдер; старый SVOX/Google-робот искать отдельно, не смешивая с текущим Google.
