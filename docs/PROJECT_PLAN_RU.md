# План VoiceService

## Сделано

- PTT по правому Ctrl.
- Toggle-диктовка по Scroll Lock.
- Нарезка длинной Scroll Lock-диктовки по паузе.
- Пробел между частичными chunk-результатами.
- Окно настроек из трея и double-click по иконке.
- История последних текстов текущего запуска.
- Кэш последних аудиозаписей.
- Чтение буфера и выделенного текста.
- Двойной короткий правый Ctrl для чтения выделенного текста.
- TTS-провайдеры: SAPI, Piper, Silero, Yandex, тестовый Google-robot.

## В работе / нужно довести

- Убрать Windows SAPI из обычного сценария: голос стабильно работает, но звучит непригодно. Пока оставить только как временный smoke-test/fallback.
- Проверить Piper после фикса UTF-8 stdin. Если качество всё ещё плохое, удалить или заменить русскую модель.
- Проверить Silero после переноса PyTorch cache в `runtime/tts/silero`; все модели должны быть внутри проекта.
- RHVoice: отдельного portable CLI сейчас нет. На Windows это SAPI-voice installer; если ставить RHVoice, он должен появиться в списке Windows SAPI, а не отдельным сломанным провайдером.
- Yandex: держать выпадающие списки голосов и ролей, без ручного угадывания значений.
- Сохранять последние результаты распознавания на диск, чтобы можно было диагностировать потери текста после перезапуска.
- Проверить, почему отдельные chunk-распознавания иногда стартуют с заглавных букв или теряют первый сегмент.
- После завершения работ удалить `VOICE_SERVICE_TZ.md`, потому что там были секреты и мусор кодировки.

## Текущие приоритеты

1. Стабильная диктовка: PTT и Scroll Lock не ломать.
2. Чистые chunk-стыки: пробел есть, случайное троеточие на паузе убирается.
3. Читалка: Yandex как рабочий эталон, Silero/Piper как локальные кандидаты, Windows SAPI только временный fallback. Google-robot оставить как отдельный robot/fun-пресет.
